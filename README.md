## Tentang

AICLUB adalah komunitas dan layanan gratis untuk pengguna AI Indonesia — dari pemula sampai developer. Kami merangkum tools AI open source dalam bahasa Indonesia, menyediakan subdomain dan tools gratis, dan memandu UMKM, kreator, serta developer memakai AI secara praktis.

## Kontribusi

Punya tool AI open source favorit? Buka **Issue** di repo [tools](https://github.com/AIClub-ai-id/tools) dengan format:

1. Nama + link repo tool
2. Kenapa layak masuk katalog (manfaat untuk pengguna Indonesia)
3. Kategori (developer / UMKM / kreator)

Syarat: open source, aktif dirawat, dan relevan untuk pengguna Indonesia.
